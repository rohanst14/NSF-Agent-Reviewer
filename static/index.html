NSF Proposal Review Automation

Multi-agent based NSF Grant Reviewer

This app runs a true multi-agent review workflow on your machine through a local Python server. The browser only handles input and display. One compliance review, three full NSF-style reviewers, and final panel consensus.

Serve locally from python3 nsf_reviewer_server.py and open http://127.0.0.1:8000.
Pipeline
  1. Compliance review
  2. Reviewer A, B, C in parallel
  3. Round 1 positions
  4. Round 2 counter-points
  5. Round 3 final votes
  6. Consensus synthesis
